# Neon Postgres + Cloudflare R2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move all of AI Factory's data from the local SQLite file to Neon Postgres and its images to Cloudflare R2, copy the user's existing data, and let a second computer open the same tasks.

**Architecture:** Drizzle moves from `sqlite-core`/`better-sqlite3` to `pg-core`/`node-postgres` (app) and `pglite` (tests); every database call becomes async. A small storage module talks to R2 over the S3 API. Per-computer facts (project folder, prepared base, where a run's worktree lives) move behind a machine id; decisions made elsewhere are relayed through the database by the run's own computer.

**Tech Stack:** Next.js 16, Drizzle ORM 0.45, `pg`, `@electric-sql/pglite`, `@aws-sdk/client-s3`, Vitest, Inngest.

**Spec:** `docs/superpowers/specs/2026-11-11-neon-r2-design.md`

## Global Constraints

- Secrets only in `.env.local`: `DATABASE_URL`, `DATABASE_URL_UNPOOLED`, `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`. Never in code, git, logs, event payloads or the browser.
- App connects with `DATABASE_URL_UNPOOLED` (direct). Tests use PGlite, never Neon.
- Table and column names unchanged; SQLite integer booleans become `boolean`; timestamps stay ISO text; JSON stays text.
- Event sequences per run: gap-free, increasing, unique; `(run_id, sequence)` unique index kept.
- Event stream: poll every 1000 ms only while the run is `queued | running | waiting_approval`; send replay + `caughtup` and close when the run has ended.
- Decision relay: every 5000 ms, on the run's own machine.
- R2 keys: `snapshots/<runId>/<shot>.png`, `attachments/<attachmentId>.<ext>`. Images are streamed through the app.
- Machine id in `.factory/machine.json` (`{ id, name }`), name from the host name.
- The SQLite file is never written by the copy and never deleted.
- All user-facing text through `src/ui/strings.ts`.

## Review Focus

1. Neon unreachable at page load → a plain banner, not empty lists (Task 7 test: the canvas page with a failing db shows `strings.dbDown`).
2. Copy run twice → second run copies nothing and reports equal counts (Task 8 test).
3. A run started on machine A opened on machine B → no worktree buttons, says where it is (Task 6 test).
4. Two writers appending events to one run at once → sequences 1..N with no gap or duplicate (Task 3 test).
5. An image route asked for `../x` or an unknown shot → 404, never an R2 read (Task 5 test).
